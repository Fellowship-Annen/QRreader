# フィラメント管理・新窓口

この portal-preview フォルダを既存QRreaderリポジトリの直下に追加して公開します。
ルートの旧 index.html、manifest.json、register.html は変更しません。

## 公開先

旧ページのURLが `https://アカウント.github.io/QRreader/` なら、新窓口は
`https://アカウント.github.io/QRreader/portal-preview/` です。
GitHub Pagesへ反映された後にスマホでこの新URLを開き、ホーム画面へ追加してください。
アプリ名は「新窓口」です。開始URL・表示対象範囲・アプリ識別子をこのサブフォルダ内に設定しています。
既存のホーム画面アイコンは旧ページ用としてそのまま使えます。

## QR互換性

- 旧QR：GoogleフォームURLの `entry.268306040` から管理番号を取り出します。フォームを開いたり送信したりしません。
- 新QR：この窓口の `index.html?id=S26092801` から管理番号を取得できます。
- アプリ内カメラ：QR自動認識 → カメラ停止 → GAS照合 → 同じ画面に表示。
- 通常カメラ：新QRのURLを開くとIDから情報取得します。旧フォームQRを通常カメラで開けば、従来どおりフォームが開きます。

## データについて

このフォルダは新旧の画面を分けるもので、テスト用の別台帳ではありません。
設定済みのGASと在庫一覧は本番のデータです。「重量を更新」「この場所に変更」は実際の台帳と操作ログを更新します。
公開・更新操作は利用者が行います。フォルダ作成時点ではデータの書込み試験やGitHubへのpushは行っていません。

担当は既存名から選択／新規入力できます。検索はメーカー・素材・色の順に絞り込みます。
入荷登録ページと新QRの生成機能はこのフォルダにはまだ含めていません。

カメラはHTTPSで利用してください。通信を伴うアプリで、オフラインでの読み書きには対応していません。
ホーム画面への追加方法やインストール表示は端末・ブラウザによって異なります。
更新通信が途切れた場合は自動再送せず、台帳・操作ログを確認してから再開してください。

完成後もこのURLを継続使用する予定なら、新QRに使えます。公開先を後で変える場合は、QRに記録した旧URLを残すか移行用の転送が必要です。
